# Kushon - Gaz Ballon Sinov Guvohnomasi Tizimi

Avtotransport vositalariga o'rnatilgan gaz ballonlarini texnik ko'rik va sinovdan o'tkazish hamda rasmiy guvohnoma (blanka) berish avtomatlashtirilgan tizimi.

## 🌐 Netlify Deploy Sozlamalari (Juda Muhim!)

Agar ushbu loyihani **Netlify**ga yuklayotgan bo'lsangiz:
- **Build command:** `npm run build`
- **Publish directory:** `dist`

Loyihaning ildizida tayyor `netlify.toml` va `public/_redirects` fayllari yaratilgan, shuning uchun Netlify bu sozlamalarni avtomatik taniydi.

## 🚀 Ishga tushirish

```bash
# 1. Bog'liqliklarni o'rnatish
npm install

# 2. Dasturni ishga tushirish (development)
npm run dev

# 3. Loyihani ishlab chiqarish uchun yig'ish (build)
npm run build
```
